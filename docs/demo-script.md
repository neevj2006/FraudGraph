# Local demonstration

Use the generated synthetic dataset and the local token. `demo.webm` records the automated analyst workflow. Do not publish real dataset rows or credentials.

1. Open the queue and explain that these are synthetic transactions, ranked by a calibrated estimate.
2. Choose a high-scoring transaction. Compare the selected model with logistic regression and the raw R-GCN score; point out calibration differences.
3. Select graph nodes, zoom and fit. Explain that the initial canvas focuses on shared signatures, while the accessible entity list includes the full evidence snapshot. Check truncation and cutoff.
4. Record an investigating disposition and a note about additional context needed. Export the case and open the audit trail.
5. Open the model registry and connect the visible version to the experiment report. Discuss where graph statistics beat the GNN on value capture, and why public benchmark evaluation does not establish operational suitability.

The demo uses synthetic data. Full-data evaluation is an offline research comparison; production deployment and analyst validation are separate requirements.
